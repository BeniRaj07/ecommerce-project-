# Traditional / Local product photos

`backend/data/products.js` points the 12 "Traditional / Local" seed products
at filenames in this folder. Drop in your own photos (or properly licensed
stock) using these **exact filenames** and they'll show up automatically —
no code changes needed. Nothing is scraped or copied from third-party sites
here; these are placeholders until you supply real images.

| Product                        | Expected filename              |
| ------------------------------- | ------------------------------- |
| Traditional Red Jutti           | `red-jutti.jpg`                 |
| Handmade Brown Leather Jutta    | `brown-leather-jutta.jpg`       |
| Black Embroidered Jutti         | `black-embroidered-jutti.jpg`   |
| Golden Wedding Jutti            | `golden-wedding-jutti.jpg`      |
| Newari Bridal Jutta             | `newari-bridal-jutta.jpg`       |
| Multicolor Thread Work Jutti    | `multicolor-jutti.jpg`          |
| Handmade Leather Mojari         | `leather-mojari.jpg`            |
| Red Velvet Wedding Jutti        | `red-velvet-jutti.jpg`          |
| Nepali Handmade Sandal          | `nepali-handmade-sandal.jpg`    |
| Brown Leather Slipper           | `brown-leather-slipper.jpg`     |
| Handmade Jute Shoes             | `handmade-jute-shoes.jpg`       |
| Maroon Embroidered Jutti        | `maroon-embroidered-jutti.jpg`  |

Until a file is added, that product's image will show as broken in the
browser — everything else about the listing (name, price, filters) still
works.

You can also just re-upload any image through the admin product editor
(Products → Edit → Image) instead of touching files directly; either way
works.
